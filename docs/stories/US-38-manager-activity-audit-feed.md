## Story

As an Activity Manager, I want a centralised team-wide audit log of recent activity and changes across all bookings so that I can review recent updates at a glance without having to manually dig through individual sessions.

## Acceptance criteria

- Provides a centralised feed view tracking system-wide lifecycle updates (such as booking creations, confirmations, cancellations, and metadata shifts).
- Filters and displays activity streams according to manager permissions.
