## Story

As a recipient of a shared booking link, I want to view a clean summary of event details without needing to log in so that I can quickly check basic arrangements.

## Acceptance criteria

- Unauthenticated visitors opening a booking URL are presented with a streamlined, read-only public summary view displaying core event metadata (such as date, time, venue, and activity type) without hitting a login wall.
