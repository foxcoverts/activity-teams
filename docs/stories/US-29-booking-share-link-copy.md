## Story

As an Activity Manager or Team Member, I want a convenient UI action to copy a booking link directly to my clipboard so that I can easily share event details via external messaging tools.

## Acceptance criteria

- Provides a clear share action trigger (such as a copy-link button) on booking views that instantly copies the canonical URL to the user's clipboard with a visual confirmation toast.
