## Story

As an Activity Manager, I want visual status and role badges displayed alongside user profiles so that team rosters and member states can be scanned quickly.

## Acceptance criteria

- Highlights inactive accounts and distinct team roles across member directories and management views.

## Progress

A manager is a sky badge with a star, and a member is a gray badge with a person icon, on the team member list, each team membership, and the Admin user view (Manager if they manage any team, otherwise Member). Members and Admin Users both use Account status for lifecycle, including Suspended, Deleted, and invitation states. Admin Users also shows access flags in Roles. The old global role is not a separate badge.
