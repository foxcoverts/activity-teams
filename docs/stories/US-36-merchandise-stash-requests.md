## Story

As a team member, I want an easy way to submit requests for new stash or equipment orders so that I can order clothing, neckers, or kit through the team.

## Acceptance criteria

- Provides a member-facing interface or form to submit requests for merchandise, clothing sizes, and equipment.
- Notifies relevant managers when a new order request is submitted.
